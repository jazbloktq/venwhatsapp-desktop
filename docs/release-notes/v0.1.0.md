## Venwhatsapp Desktop 0.1.0

Initial Windows desktop release.

- WhatsApp Web opens in a native Windows window with a system tray and Start Menu shortcut.
- Automatic startup is enabled by default and opens the app hidden in the tray.
- Live edits and deletions are logged and can raise Windows notifications. Changes that happened before the logger starts stay out of the drawer and do not trigger notifications.
- Existing WebView2 login data is reused from `%LOCALAPPDATA%\Venwhatsapp Desktop\WebView2`.
- The English-only settings interface includes update checks for future GitHub Releases.
- NSIS and MSI installers include WebView2 bootstrapper handling; the app has no .NET runtime dependency.
