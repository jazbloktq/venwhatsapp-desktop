## Venwhatsapp Desktop 0.3.0

- Reordered the Security settings and redesigned the Privacy blur dropdown with grouped, dependent controls and an opening animation.
- Added a rounded hover highlight to the Privacy blur dropdown and completed English translations for its settings.
- Smoothed the Settings panel opening and closing transition.
- Anchored the Settings content fade to the bottom of the scroll area so it stays in place as the window is resized.
- Added a History side panel with message-type and chat filters, plus a History settings tab for media capture, export, and confirmation-protected clearing.
